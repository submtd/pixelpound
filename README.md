# PixelPups

Mint a $5 pixel pup on Solana devnet: https://submtd.github.io/pixelpups/

- `gh-pages` holds the built site.
- `main` holds the crank: a scheduled workflow that reveals fulfilled mints and claims pups whose sell-back window closed (they default to kept). `crank.mjs` is a bundled build; the source is private.

Both branches are generated by a deploy workflow. Don't edit them by hand.
